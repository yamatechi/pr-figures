#212 タイムラインをサムネイルで出し、判定を通った写真だけを公開する

スマホでタイムラインが重く、確認前の写真が誰にでも見えていたため、投稿と表示の流れを分ける

これまで

タイムラインを開く

一覧の API
→
原本（1 枚 数 MB）をそのまま読む
20 枚で数十 MB。モバイル回線では表示に 10 秒以上かかる

写真を投稿する

写真を送る
→
すぐに公開
不適切な写真も、確認される前にフォロワーへ届く

この PR のあと

タイムラインを開く

一覧の API
→
サムネイル（CDN）を読む
原本は詳細画面で拡大したときだけ読む

写真を投稿する

写真を送る
→
処理待ち
→
サムネイル作成・判定
→
公開
処理待ちの間は、投稿した本人にだけ「処理中」と見える
既存の投稿のサムネイルは別のスクリプトで作る。作り終えるまでは、サムネイルの無い投稿だけ原本を出す
